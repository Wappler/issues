# Reporting a security problem

Please do not open a public issue for a security problem. [Report it privately](https://github.com/Wappler/issues/security/advisories/new): only the Wappler team sees it.

Say what is affected (Wappler's version, the server model, the extension), how to reproduce it, and what someone could do with it. We answer within a few working days and tell you when the fix is out.
