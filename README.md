# Wappler issues

The public place to report something in Wappler that does not work, and to follow it until it is fixed.

## Before you open an issue

- **A question, or how do I…?** Ask on the [community forum](https://community.wappler.io). More people read it, and answers stay findable.
- **An idea or a wish?** Share it on the forum too (in Wappler: Help › Share an idea), so others can vote and add to it.
- **A security problem?** [Report it privately](https://github.com/Wappler/issues/security/advisories/new), never as a public issue.
- **Something does not work?** That belongs here. Search the [open issues](https://github.com/Wappler/issues/issues) first: if yours is there, add a 👍 and your details instead of a new one.

## How to report a problem

1. In Wappler, choose **Help › Report a problem**. It sends this session's log and a screenshot **privately** to the Wappler team and gives you a **report id**. The log holds this session only and never your passwords, keys or project data.
2. [Open an issue](https://github.com/Wappler/issues/issues/new/choose), paste the report id, and write the steps that make it happen.
3. One problem per issue, so each can be fixed and closed on its own.

This page is public: never paste a password, API key, token, connection string or customer data here.

## What happens next

| Label | Means |
| --- | --- |
| `new` | Not looked at yet. |
| `needs info` | We need something from you (often the report id or the steps). Closed after 14 days without an answer, reopened when it comes. |
| `confirmed` | We can make it happen too. |
| `planned` | It is in a coming version. |
| `fixed` | Fixed; the comment names the version that has it. |
| `duplicate` | Already reported; the comment links the issue to follow. |
| `not a bug` | Works as designed; the comment says why and where to suggest a change. |

The area labels (`design`, `server`, `database`, `publish`, `setup`, `extensions`, `mobile`) and the computer labels (`windows`, `macos`, `linux`) say where it happens.
